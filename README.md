## 👋 Hello there

We are [Tideways](https://tideways.com): a small, focused team building a **PHP profiling, monitoring and exception tracking platform** that helps developers understand and improve the performance of their applications in production.

We're based in Germany, and our team has deep roots in the PHP ecosystem — from core contributions to projects like Doctrine and Xdebug, to authoring RFCs that have shipped in PHP itself. GitHub is one of the places where we share that work with the community.

You can [sign up for a free trial of Tideways](https://app.tideways.io/register) for PHP Profiling and Monitoring.

### Our commitment to open source

Tideways is built on top of quality open-source software, and we consider it a given to give back — with time, code, or financial contributions. A few of the ways we do that:

- **Founding member of the [PHP Foundation](https://opencollective.com/phpfoundation)**, helping to promote and advance the PHP language.
- **Signatory of the [Open Source Pledge](https://opensourcepledge.com/)**, committing to sustained financial support for the open-source projects we depend on.
- **Business Sponsor of [Xdebug](https://xdebug.org/)**, supporting Derick Rethans' work on the debugging extension every PHP developer relies on.
- **Sponsor of [PHPUnit](https://phpunit.de/)**, backing Sebastian Bergmann's long-term maintenance of the testing framework at the heart of our toolbox.
- **Active contributors to [Doctrine](https://www.doctrine-project.org)**, helping with development, maintenance and project organization.
- **Contributors to PHP itself** — the [DOM Living Standard RFC](https://wiki.php.net/rfc/dom_living_standard_api) and the [Attributes RFC](https://wiki.php.net/rfc/attributes_v2) both shipped in PHP 8.0 thanks to work done on Tideways time, and we built [PHP RFC Watch](https://php-rfc-watch.beberlei.de) to make the RFC process easier to follow.

You can read more about all of this on our [open-source commitments page](https://tideways.com/open-source).

### Tools we share here

Alongside the upstream contributions, we publish a handful of integrations and utilities that make Tideways easier to use in real-world PHP stacks:

- **[release-action](https://github.com/tideways/release-action):** a GitHub Action to create a Tideways Release from your workflow.
- **[container-images](https://github.com/tideways/container-images):** Docker images for the different Tideways components.
- **[homebrew-profiler](https://github.com/tideways/homebrew-profiler):** Homebrew recipes for installing the Tideways Profiler on macOS.
- **[ext-tideways-stubs](https://github.com/tideways/ext-tideways-stubs):** IDE stubs for the Tideways PHP extension.
